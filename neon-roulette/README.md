# Neon Roulette
Lokalnie: `npm install && npm start` -> http://localhost:3000
Online (znajomi z dowolnego miejsca): wrzuć ten folder na GitHub i wdróż na Render.com / Railway / Fly.io
(Build: `npm install`, Start: `npm start`). Znajomi wchodzą w link, który dostaniesz od hostingu.
Szybki test bez hostingu: `npm start` + `npx cloudflared tunnel --url http://localhost:3000`.
